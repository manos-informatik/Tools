# Tools

## Vorlagen für die Klassentafel pflegen

Öffne [Klassentafel/vorlagen.ods](Klassentafel/vorlagen.ods) in LibreOffice Calc und füge im ersten Tabellenblatt pro Vorlage eine Zeile hinzu. In Spalte A (**Beschreibung**) kommt der Name für die Auswahl, in Spalte B (**Inhalt**) der Aufgabentext. Lass die Kopfzeile stehen und speichere unter demselben Dateinamen. Zeilenumbrüche innerhalb einer Zelle werden übernommen. Die Klassentafel übernimmt den reinen Text und setzt ihn in ihrer eigenen Schrift.

Committe die Datei und pushe sie zu GitHub. Sobald GitHub Pages die Änderung veröffentlicht hat, erscheint die Vorlage beim nächsten Öffnen über den **V**-Button. Für die lokale Vorschau öffne die Klassentafel über einen lokalen Webserver.
